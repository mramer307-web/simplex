# SIMPLEX

## التشغيل على جهازك

1. استخدم Node.js بإصدار 22.13 أو أحدث.
2. انسخ `.env.example` إلى ملف باسم `.env`، واضبط `ADMIN_USERNAME` و`ADMIN_PASSWORD`. استخدم كلمة مرور فريدة لا تقل عن 12 حرفاً؛ كلمة المرور القصيرة مناسبة للاختبار المحلي فقط. ملفات `.env` محلية ولا ترفعها إلى GitHub؛ ارفع `.env.example` فقط كقالب بلا أسرار.
3. شغّل `npm install`، ثم شغّل مهمة **Start SIMPLEX website** من `Terminal > Run Task` في VS Code، أو نفّذ `npm run dev` في الطرفية.
4. افتح رابط Vite الظاهر في الطرفية. سيعمل الخادم وقاعدة SQLite معه تلقائياً.

زر **Go Live** الخاص بإضافة Live Server لا يشغّل Vite أو API، لذلك استخدم مهمة VS Code أو أمر `npm run dev` لعرض الموقع بكامل وظائفه.

تُحفظ طلبات الانضمام والرعاية في `data/simplex.sqlite`، وتبقى بعد إغلاق الموقع وإعادة تشغيله. الإحصائيات تعرض سجلات قاعدة البيانات، لذلك تبدأ الأعداد بصفر في قاعدة جديدة. تظهر الطلبات الجديدة في لوحة الإدارة تلقائياً خلال ثوانٍ.

## النشر

استخدم استضافة Node.js تدعم قرصاً دائماً قابلاً للكتابة، واضبط `ADMIN_USERNAME` و`ADMIN_PASSWORD` بكلمة مرور قوية وفريدة، واضبط `COOKIE_SECURE=true` عند استخدام HTTPS، واجعل `DB_PATH` على القرص الدائم. ابنِ الواجهة بالأمر `npm run build` ثم شغّل `npm start` في بيئة الإنتاج (`NODE_ENV=production`). الملفات المؤقتة لدى بعض الاستضافات تُحذف عند إعادة النشر، لذا لا تضع قاعدة البيانات عليها، وخذ نسخة احتياطية منها بانتظام.
